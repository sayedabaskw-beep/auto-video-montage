# Auto Video Montage

مشروع بسيط لدمج الفيديوهات تلقائياً باستخدام:
- واجهة ويب عربية مبسطة
- Node.js + Express
- FFmpeg
- تحميل ملف اللوجو + الفيديو التعريفي + الفيديو الأساسي

## متطلبات التشغيل

- Node.js 18+
- FFmpeg (يتم استخدام ffmpeg-static تلقائياً داخل المشروع)

## التثبيت

```bash
npm install
```

## التشغيل

```bash
npm start
```

ثم افتح المتصفح على:

```bash
http://localhost:3000
```

## ملاحظات

- اللوجو يُوضع في أعلى اليمين طوال مدة الفيديو.
- الفيديو التعريفي يظهر أولاً ثم الفيديو الرئيسي.
- النتيجة تُحفظ داخل مجلد `output`.
- يمكن إعادة تشغيل العملية بعد تغيير الملفات بسهولة.
